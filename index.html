Die Anzahl der Datensätze ist keine Feststellung, dass eine Partei „mehr Skandale“ verursacht. Ein Datensatz kann beispielsweise einen Vorwurf, eine Prüfung, eine Aussage, ein Ermittlungsverfahren oder eine Gerichtsentscheidung dokumentieren. Eine redaktionelle Skandal-Einstufung bleibt davon getrennt.
