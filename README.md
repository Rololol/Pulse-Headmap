# PULSE — Global History & Disaster Atlas

Interaktive historische Datenvisualisierung für Katastrophen, Konflikte, Pandemien, Hungersnöte und andere Ereignisse mit hohen Opferzahlen.

## Prinzipien

- Todeszahlen werden möglichst als Spannweiten gespeichert.
- Direkte und indirekte Todesfälle werden getrennt betrachtet, wenn die Quellen das erlauben.
- Religionen werden nicht als pauschale Täterkategorien behandelt.
- Religiöse Faktoren werden als Kontext eines Ereignisses dokumentiert.
- Akteure, Staaten, Regierungen, Organisationen und Ideologien werden getrennt erfasst.
- Jede Zahl soll mit Quellen und einem Vertrauensgrad versehen werden.

## Aktueller Stand

Dies ist ein Prototyp mit einer kleinen, kuratierten Beispieldatenbasis. Die Datenbank ist bewusst noch nicht vollständig.

## GitHub Pages

Die Seite besteht aus statischen Dateien und kann über GitHub Pages veröffentlicht werden.
