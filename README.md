# Politik / Transparenz

Quellenbasierte Weboberfläche für politische Vorgänge in Deutschland.

## Prinzipien
- Keine pauschalen Schuldbehauptungen.
- Statuswerte trennen dokumentierte Vorgänge, Vorwürfe, Ermittlungen und rechtskräftige Verurteilungen.
- Lobbyismus und Interessenkonflikte werden nicht automatisch als Straftaten dargestellt.
- Jeder Datensatz braucht Quelle und Datum.
- Keine politischen Rankings oder „Korruptionsscores“.

## Ausbau
Die Beispieldaten liegen zunächst in app.js. Für den produktiven Betrieb sollte daraus eine versionierte JSON-Datenbank werden, mit Person, Amt, Vorgang, Kategorie, Status, Zeitraum, Beschreibung, Primärquelle, Sekundärquellen, Dokumenten, Rechtsstatus und letzter Prüfung.
